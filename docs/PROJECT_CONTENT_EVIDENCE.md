# Published project claim ledger

Reviewed November 24, 2026 (America/Phoenix). This ledger covers the significant claims and numerical labels in the four updated case studies. Each project's exact source commit applies to every row in its table. Paths are repository-relative; links resolve to immutable public source snapshots. Source code establishes implementation, while executed reports establish the stated validation scope. Reported source-project tests were inspected, not rerun here.

Statuses: **implemented** = directly supported by source; **report + artifact** = executed report cross-checked against a local result artifact; **reported** = source validation report, not independently rerun; **historical** = preserved earlier portfolio evidence with missing original metric logs; **open/failed** = an explicit limitation, not a completed capability. Roadmaps and smoke fixtures do not establish experimental success.
